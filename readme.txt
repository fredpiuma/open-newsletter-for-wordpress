== Description ==

Open Newsletter is a free, open-source newsletter plugin (GPLv2 or later).

* Unlimited subscribers, lists, custom fields and subscription forms (popup, widget, shortcodes, raw HTML)
* Double opt-in, privacy checkbox, anti-spam and anti-flood
* Drag and drop composer and responsive emails
* Delivery engine with throttling and bounce/error tracking
* Complete open and click statistics: per subscriber, per link, per newsletter, CSV export and "add to list" from any filter
* CSV import and export of subscribers
* No license, no premium locks, no telemetry, no remote requests made by the plugin

The slug, text domain, prefixes and database schema are the same of the original plugin, so you can move your data in both directions.

Source code, documentation and issues: https://github.com/fredpiuma/open-newsletter-for-wordpress

== Installation ==

1. Use the ZIP built with `tools/build-zip.sh` (it contains the `newsletter/` folder) and upload it in Plugins > Add New > Upload Plugin.
2. Activate it. Do not keep the original Newsletter plugin active at the same time.
